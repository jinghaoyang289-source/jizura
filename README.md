# JIZURA — 我的备份站

这是 [852wa/JIZURA](https://github.com/852wa/JIZURA)（作者 852wa / hakoniwa）的备份部署，
版本 v0.13.0，工具本体为 **MIT 协议**（见 LICENSE），原作者已在 README 里写明可以 Fork 后在自己的仓库公开。

- 打开方式：仓库开 GitHub Pages 后，用 `https://<用户名>.github.io/jizura/zh-hans/` 打开简体中文版，
  根目录是日文版，`/en/` 是英文版。
- 包含的文件：根目录 `index.html`、简体中文版 `zh-hans/index.html`、英文版 `en/index.html`、MIT 协议 `LICENSE`。
- 语言切换：日文 / 简体中文 / 英文三个版本之间在本站内切换；印尼文、韩文、越南文、繁体中文这四个版本本站没有收录，
  点它们会跳回原作者的站。
- 注意：字体是按需从 Google Fonts 加载的，国内打开时如果 Google Fonts 打不开，会自动用系统字体代替，功能不受影响。
  歌词和音频只在浏览器本地处理，不上传服务器。
- AE 面板（JIZURA_AE.jsx / CEP 版）本站没有收录，需要的话去原仓库下载。
